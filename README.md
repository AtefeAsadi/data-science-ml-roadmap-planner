# Data Science & Machine Learning Roadmap Planner

Free 24-week project based Data Science & Machine Learning roadmap planner.
This planner is designed to help learners move step by step from programming and statistics foundations to machine learning, practical projects, and a final capstone.

## What's Inside?

- 24-week structured learning roadmap
- 14 learning chapters
- Python fundamentals
- Git & reproducibility
- SQL & relational data
- NumPy & pandas
- Data cleaning & wrangling
- EDA & data storytelling
- Math for Machine Learning
- Probability & Statistics
- Statistical Inference & A/B Testing
- Regression & Generalized Linear Models
- Machine Learning workflow & evaluation
- Supervised Learning
- Unsupervised Learning
- Neural Networks
- Practical project deliverables
- Capstone project
- Reading recommendations
- Reflection & progress tracking

## Learning Approach

The roadmap follows a prerequisite-based sequence:

**Programming & Data → Statistics & Probability → Modeling → Validation → Communication → Capstone**

Each chapter includes a practical deliverable so learners can build a portfolio while studying.
